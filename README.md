# 星栞 Hoshiori

Android 纯本地游戏签到工具。授权、计划和签到记录保存在手机上，由手机直接访问社区服务；无需自建服务器、Root 或 Shizuku。

当前版本：**0.6.0**（Android 8.0+，target SDK 35）。由原 GlassSign 项目增量升级，保留安装包标识和本机存储以兼容覆盖安装。

## 使用

1. 打开第二页「绑定」，选择游戏并登录对应账号体系。
2. 读取角色后，勾选该账号下需要签到的游戏，再确认绑定。同一账号体系下共用本次授权，不需要逐个游戏登录。
3. 已有账号可在菜单选择「管理游戏」，使用现有授权重新查询和选择游戏。不同账号保持独立，不自动合并。
4. 首页手动检查，或在设置中启用每日后台计划；各项结果显示在第三页「记录」。

支持的游戏配置：原神、崩坏：星穹铁道、绝区零、崩坏3、明日方舟、终末地、异环、鸣潮、战双帕弥什。配置支持和离线测试通过不代表所有真实账号都已验收。

异环提供本应用明确标识的账号/短信表单，信息仅发送账号服务，密码与验证码不保存。其他账号体系沿用应用内网页登录或高级授权导入。登录成功后仍需官方角色查询及用户确认，头像登录状态本身不等于签到授权可用。

## 结果与后台行为

- 官方状态确认已签时显示「已签到」；当天已有本机成功记录时不会重复提交，并注明本地记录来源。
- 提交中断且结果未知时要求人工核对，不自动重复消费请求。
- WorkManager 合并重复任务、等待网络、重启恢复计划；Android 系统可能延迟后台任务，不保证精确到点执行。
- 升级保留旧账号、加密授权、暂停状态和记录；新加入的崩坏3不会自动加入旧账号的签到范围。旧密钥已经丢失的授权仍需要重新登录。

## 界面

底部首页／绑定／记录三页。主题支持系统／浅色／深色、纯黑、自定义主色、动态配色、四种色彩风格、字号和字体选择。参考 FlClash 的功能组织，使用 Compose 独立实现；表面层次和导航融合为静态效果，不包含实时液态玻璃着色器。

## 构建与验证

需要 JDK 17、Android SDK 35。首次构建需要网络下载依赖。

```shell
cd android
./gradlew --no-daemon :app:assembleDebug :app:testDebugUnitTest :app:assembleDebugAndroidTest :app:lintDebug
```

Debug 安装包：`android/app/build/outputs/apk/debug/app-debug.apk`。请查看发布资产及 SHA-256；不同签名的 APK 不能直接覆盖安装。首次公开发布沿用本地开发签名，CI 构建使用独立调试签名，不作为原安装的更新包。
