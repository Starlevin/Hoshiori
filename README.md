## 使用流程

四个主导航固定为首页、账号、记录、设置。

1. 账号页右上角+ → 选择平台 → 登录账号 → 选择游戏/角色 → 完成绑定。
2. 同一平台可添加主号、小号，各自拥有独立加密授权与记录；一个平台账号管理多个游戏和角色。
3. 账号详情可使用现有授权管理游戏/角色。绑定保存不强制签到，需要时点击立即签到。
4. 设置中开启全局每日计划，并管理每个账号是否参加自动签到；系统可能延迟，不承诺精确到点。

已有账号重新授权时默认保留已选范围与自动签到偏好。已知稳定平台身份重复添加时定位原账号；身份未知时提示核对，不能按昵称或令牌猜测合并。

## 结果与数据

- 分别展示授权可用、绑定完成、官方已签到、提交已接受、结果待确认。
- 已完成项自动跳过；未知提交不会盲目重发。只读状态校验与执行签到是不同操作。
- 暂停、解除授权、删除历史、删除整个账号各自独立；清历史仍保留当天提交保护。
- schema1/2/3/4/5→6增量迁移，并保存应用私有检查点；历史受理记录不会批量转为成功，失败时展示保留数据的恢复入口。
- 密码、验证码不保存。已有本机授权继续由原系统密钥保护；跨设备迁移和卸载后恢复密钥不作保证。

现有游戏配置保留：原神、崩坏：星穹铁道、绝区零、崩坏3、明日方舟、终末地、异环、鸣潮、战双帕弥什。本轮没有逐平台重新验证实号登录与签到，不能据此宣称全部可用。

## 原生界面

Jetpack Compose实现四页与独立悬浮Dock。选中胶囊使用弹性过渡；标准材质采样真实页面并局部模糊，文字图标单独绘制。API31以下、低内存、省电、触摸探索以及用户轻量/关闭设置使用回退。尊重系统减少动画与字号，支持深浅色、主色、动态色和字体设置。

设置首页分为使用偏好、运行与扩展、应用与数据；详细选项进入各自子页。外观分为主题预设、主题色、页面背景、玻璃与动效、字体与排版。经典黑白采用中性黑灰 / 白灰底色；深蓝与柔紫由用户主动选择。已有自选颜色、动态取色与背景保留，旧版默认蓝色外观只迁移一次。

标准 Android13+ 动效模式直接使用 Apache-2.0 的 Backdrop 库与上游 catalog 标签栏组件；图标、文字及页面共同参与透镜合成。低版本或减少动效等条件保留回退。未复制 FlClash Dart 或 Nexio AGPL 应用代码，不宣称跨设备视觉完全相同。旧版主题映射见[参考记录](docs/frontend-flclash-20261102.md)。

## 构建与交接

需要JDK17、Android SDK36（targetSdk仍为35）。首次构建需要下载依赖。

```shell
cd android
./gradlew --no-daemon --max-workers=2 :app:assembleRelease :app:testReleaseUnitTest :app:lintRelease
```

默认仅构建 Release。上述 Gradle 命令生成未签名 APK，不能直接分发；维护者 Windows 可运行 `android/build-release.ps1` 完成检查及既有正式签名校验。CI 的 unsigned 构建只供验证。正式签名自 v0.7.5 固定；覆盖升级须同包名、同签名，不要先卸载或清数据。旧 `.debug` 测试包数据不会自动共享到正式包。每次正式发布同步 GitHub 与夸克，见[发布流程](docs/RELEASE_PROCESS.md)。
