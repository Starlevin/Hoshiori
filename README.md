# 星栞 Hoshiori

Android 纯本地游戏签到工具，由手机直接访问社区服务；不依赖自建云服务器、Root或Shizuku。

当前分支：**v0.7.5 开发候选**。保留原安装包标识、密钥别名和本机数据，支持增量覆盖升级。新增[Dock拖动、分项反馈与森空岛续期/状态核对](docs/v075-report.md)，前版的[Android签名转义修复](docs/v074-report.md)、[设备缓存解析修复](docs/v073-report.md)及[可选领签扩展](docs/v072-report.md)继续保留。请同时阅读[15项验收矩阵与限制](docs/v070-report.md)，自动化通过不代表四社区实号或所有真机条件已通过。

## 使用流程

四个主导航固定为首页、账号、记录、设置。

1. 账号页右上角+ → 选择平台 → 登录账号 → 选择游戏/角色 → 完成绑定。
2. 同一平台可添加主号、小号，各自拥有独立加密授权与记录；一个平台账号管理多个游戏和角色。
3. 账号详情可使用现有授权管理游戏/角色。绑定保存不强制签到，需要时点击立即签到。
4. 设置中开启全局每日计划，并管理每个账号是否参加自动签到；系统可能延迟，不承诺精确到点。

已有账号重新授权时默认保留已选范围与自动签到偏好。已知稳定平台身份重复添加时定位原账号；身份未知时提示核对，不能按昵称或令牌猜测合并。

## 结果与数据

- 分别展示授权可用、绑定完成、官方已签到、提交已接受、结果待确认。
- 已完成项自动跳过；未知提交不会盲目重发。只读状态校验与执行签到是不同操作。
- 暂停、解除授权、删除历史、删除整个账号各自独立；清历史仍保留当天提交保护。
- schema1/2/3/4→5在事务中迁移，并保存应用私有检查点；失败时展示保留数据的恢复入口。
- 密码、验证码不保存。已有本机授权继续由原系统密钥保护；跨设备迁移和卸载后恢复密钥不作保证。

现有游戏配置保留：原神、崩坏：星穹铁道、绝区零、崩坏3、明日方舟、终末地、异环、鸣潮、战双帕弥什。本轮没有逐平台重新验证实号登录与签到，不能据此宣称全部可用。

## 原生界面

Jetpack Compose实现四页与独立悬浮Dock。选中胶囊使用弹性过渡；标准材质采样真实页面并局部模糊，文字图标单独绘制。API31以下、低内存、省电、触摸探索以及用户轻量/关闭设置使用回退。尊重系统减少动画与字号，支持深浅色、主色、动态色和字体设置。

参考FlClash的交互组织，独立实现Android绘制；未复制其Dart、品牌素材或专有材质，不宣称与其视觉或Apple Liquid Glass完全等同。旧版主题映射见[参考记录](docs/frontend-flclash-20261102.md)。

## 构建与交接

需要JDK17、Android SDK35。首次构建需要下载依赖。

```shell
cd android
./gradlew --no-daemon --max-workers=2 :app:assembleDebug :app:testDebugUnitTest :app:assembleDebugAndroidTest :app:lintDebug
```

调试APK在`android/app/build/outputs/apk/debug/app-debug.apk`。覆盖升级须使用同包名、同签名的安装包，不要先卸载或清数据。CI默认调试签名不同，CI APK不能作为原手机的覆盖更新包；正式发布签名由用户另行配置。
