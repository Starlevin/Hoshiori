# 星栞 Hoshiori 0.7.2 开发与设备验证

日期：2026-11-02。基于0.7.0提交bebb61a增量开发；包名、原数据库、Keystore和账号历史保持连续。当前是开发候选，不表示四社区实号签到或全部15项验收已通过。

## 账号与森空岛

真机0.7.0已做12次导航切换、24次滚动的基线采样：P50 11ms、P95 19ms、P99 21ms，5300帧中2帧janky，PSS约183MiB；静止8秒无新增绘制。此结果不能当作本版性能提升百分比，也不能推广到其他手机。

按用户要求，后续改用MuMu Android15实例。先安装0.7.1供用户手动绑定，再在用户确认保存/退出后覆盖到0.7.2。首次安装时间保留；界面仍显示4个已绑账号、5项游戏/角色。没有清数据，没有运行会清理个人账号的完整集成夹具。

用户第二个森空岛账号绑定失败的截图同时显示空平台ID、HTTP401对应的“授权失效，请重新导入”和两个游戏“未读取到角色”。因此不能把失败仅归因于ID占位，也不能因为用户账号有游戏角色就声称接口已成功读取。

本版将ID缺失与授权失败分开说明。森空岛登录要求官方页面提供自己的设备标识，缺失时等待，不以随机UUID代替。连续两次完整会话采样一致后才交付；切换账号、改变UA、页面导航和不完整采样会重置确认，旧代次回调不能交付新会话。保留原账号和独立授权暂存，不自动签到。

这些修改减少缺字段与时序风险，**尚未证明解决第二账号的真实401**。重新登录、读取本人角色、确认绑定仍需设备实测；不伪造设备指纹，不猜测新的平台接口或稳定UID。

其他改进：授权/角色检查不再误称签到失败；真实签到目标的授权异常不声称“从未提交”；未知结果优先保留。账号摘要按确认后的实际绑定展示，旧范围未确认时明确标注。设置开关与诊断刷新连接实际业务。

## Material3与液态玻璃

保持Compose和四个主导航，插件位于设置内页。账号、记录和设置的状态、滚动、筛选及配色继续使用真实业务数据。

Dock横屏居中、最大520dp，不再铺满窗口；竖屏保留安全边距。选中胶囊弹性移动、按压反馈、文字图标独立清晰绘制，无持续循环扫光。标准模式采样实际页面裁剪，API33及以上将同一局部绘制层的GaussianBlur结果传入独立实现的AGSL折射；API31/32使用高斯模糊，低能力、省电、触摸探索、轻量/关闭模式回退。关闭模糊时不记录无用的页面采样层。

参考[FlClash Dock](https://github.com/chen08209/FlClash/blob/main/lib/ui/navigation_dock.dart)的材质与交互类别，在原生Android独立实现；没有复制其Dart、着色器、参数表或素材，也没有改变本项目许可证。不宣称与FlClash像素一致，视觉效果仍需用户确认。效果顺序依据[Android RenderEffect接口](https://developer.android.com/reference/android/graphics/RenderEffect)的同层输入和outer(inner(source))约定。

MuMu设备测试实际编译RuntimeShader并绘制红蓝窄条纹，验证采样不为空、保持不透明且高斯混色有效；截图另核对实际页面与横屏Dock。未把“编译无错误”冒充渲染验证。

## 可选领签扩展

入口：设置→插件管理。默认不下载、不安装、不启用。当前登记[领签LingQian v0.1.0-alpha](https://github.com/Starlevin/LingQian-Android/releases/tag/v0.1.0-alpha)，面向WorkBuddy国内版和Qoder CN。

当前方案是明确标注的独立应用扩展：按需下载→校验→系统确认安装→启用入口→打开领签。它不共享星栞账号、不参与星栞一键签到；其自身后台计划在领签内管理。没有复制领签源码，也没有声称实现其尚不存在的IPC协议。真实登录和积分到账未验证。

下载仅允许固定GitHub发布地址及官方CDN，尊重系统代理；结束后核验大小、SHA-256、包名、版本与证书。PackageManager读取APK元数据，系统负责安装验签，不自造APK签名解析器。FileProvider仅暴露插件缓存目录，安装与卸载均经系统界面。入口停用不卸载、不删除领签数据或停掉它自己的后台。

MuMu已实际走通首次打开未下载、点击下载、官方CDN跳转、全部校验、系统来源授权、系统安装、安装后验签及打开领签。启用/停用入口联动问题在设备测试发现后修正，最终候选已实际点击复核：停用隐藏打开按钮，启用后恢复。没有在领签中登录真实账号或领取积分。

固定包：com.qinghan.aicheckin，versionCode1，实际versionName为0.1.0；847976字节；SHA-256为7c7036d2618f20b7ce179fe2cca15664b464252a0fd54de370cb5a8b8464d787。未来更新需重新登记并验证发布包。

## 继续开发

构建：在仓库根执行 `android/gradlew.bat -p android -g .gradle-home --no-daemon --max-workers=2 :app:assembleDebug :app:testDebugUnitTest :app:assembleDebugAndroidTest :app:lintDebug`。JDK17、SDK35、Gradle8.14.3、AGP8.8.2。

本地APK保持相同调试签名，覆盖升级不先卸载。CI默认调试签名与本地不同，不能用CI包覆盖原安装。公开源码不含凭据、真实用户截图、私有日志、APK或签名私钥。

主要入口：login/SessionHarvest与WebLoginActivity处理会话；ui/LiquidDock处理页面裁剪、原生材质和降级；plugins目录处理可选下载/校验/系统操作；HoshioriScreen保留四页并提供插件设置入口。后续先完成森空岛重新授权闭环、用户视觉验收，再考虑正式合并或发布。
