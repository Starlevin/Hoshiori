# Hoshiori 星栞 v0.7.0 开发与验收报告

日期：2026-11-02。基线v0.6.0（7ef729c）。以任务书AC-01至AC-15交付。本报告分别记录实现、合成测试和真实平台验收，不把三者混为一谈。

## 本次实现

四个主导航固定为首页、账号、记录、设置。第二页账号以平台账号为父级，右上角+新增；新增顺序固定为选择平台→登录账号→选择游戏/角色→确认完成。保存不自动签到；同平台支持多个独立账号，已有账号可使用现有授权管理游戏/角色。

schema5新增平台身份、独立角色绑定、角色启用/自动签到范围、记录开始时间及结果来源。ID、加密授权容器、暂停状态、旧历史保持连续。稳定身份已知时重复账号定位原账号；平台没有稳定身份时明确提示核对，不按昵称、令牌或游戏角色猜测合并。重新授权暂存独立，默认保留已有游戏、角色与自动签到偏好，取消不替换原账号；切换其他账号时保留原更新目标。

暂停、解除授权、清理历史、删除整个账号分别确认。清理历史不清除当天提交保护。重新授权仅解锁明确因授权失效被拒绝的任务，不重置尝试次数；提交中断、响应不明或提交后状态核验失败均停止重发；米游社与异环提供只读状态校验，森空岛/库街区没有新增未经验证的查询接口，提示在官方页面核对。

首页按游戏/角色数统计，社区奖励另记；记录提供结果、平台、账号、游戏筛选，区分官方确认、既有本机记录、接口接受提交、结果未知。设置提供预计调度与实际开始/结束、通知、联网、电池约束和授权诊断。

Compose独立实现悬浮四项Dock、弹性滑动胶囊、按压反馈、真实页面背景采样与局部BlurEffect。源层只包含页面，浮层不参与自身采样；文字与图标单独清晰绘制。API31以下、低内存、省电、触摸探索和用户轻量/关闭模式回退；系统禁用动画及用户减少动效时不播放弹性动画。关闭模式使用不透明材质。参考[Android官方绘制文档](https://developer.android.com/develop/ui/compose/graphics/draw/modifiers)，没有添加第三方视觉依赖，也没有复制FlClash的Dart、图标或着色器。

## 迁移与恢复

SQLiteOpenHelper在事务中由schema1/2/3/4升级至5。升级前保存应用私有、禁止系统备份目录中的逻辑检查点（不包含授权凭据）。失败保持旧schema与记录；启动失败显示保留数据的恢复页。重试只隔离无效检查点并重新迁移，不清库、不卸载。原加密授权继续使用原Keystore别名。

不承诺跨设备密钥迁移。不要先卸载或清数据。不要直接安装旧schema APK降级；若需要人工回滚，应在独立副本中恢复检查点的旧schema并校验账号/记录，再由维护者恢复到原安装环境，保留原密钥。

## 构建、测试与设备证据

最终构建信息、SHA-256和设备结果随本地交付的BUILD_INFO.json提供。完整内部日志位于开发目录docs/evidence/v070；不把用户设备证据或授权文件提交公开仓库。

- JDK17、SDK35、Compose BOM2025.02.00；applicationId与debug后缀保留，versionCode10，versionName0.7.0。
- 构建：`android/gradlew -p android --no-daemon --max-workers=2 :app:assembleDebug :app:testDebugUnitTest :app:assembleDebugAndroidTest :app:lintDebug`。
- 最终构建、Android Lint通过；JVM单测57项通过；Android设备测试61项中57项通过、4项条件跳过。覆盖安装、断网排队、联网恢复、设备重启补漏另行执行通过，不把条件跳过算作通过。
- 设备为API35专用无真实账号模拟器，使用SwiftShader软件渲染。三键/手势导航、200%字号、横屏、TalkBack触摸探索与省电回退已有截图；实际启用TalkBack并看到焦点，但未人工核听语音。
- UI图片均使用标明“合成验证”的数据。官方密码/验证码界面没有截图。
- 早期深色截图发现继承黑色与主按钮对比度不足，已修复并加入72组配色的对比度检查；旧检查点保留作内部证据，不作为最终截图。
- 录屏期间SwiftShader采样255帧，janky83帧（32.55%），P50/P95为42/69ms；进程PSS约132MiB。这组软件渲染数据没有达到流畅度验收目标，也不能代替真机数据。不宣称60fps、耗电或流畅度提升百分比；真机性能仍是开放验收项。

## 代码入口与后续交接

MainActivity / HoshioriScreen负责四页与业务连接；AccountFlow负责平台、身份、游戏/角色和确认。HomeViewModel串联登录桥、只读管理和独立维护。SignRepository / LocalAccountBindings / MigrationSnapshot负责关系模型、暂存更新与恢复。LocalSignEngine / Providers / Protocol负责执行与只读校验。LiquidDock / Appearance / Theme负责材质、能力回退、内容色和动效。SignScheduler负责本地计划与通知。

安装调试包时必须保持包名与签名一致，不先卸载。CI默认调试签名与本地开发签名不同，不能将CI APK当作原手机的覆盖升级包。正式签名配置仍单独配置；签名密钥不随源码分发。

当前交付为待真机验收的开发候选。任务书DoD涉及真实平台、真机性能与长期后台的部分仍未完成最终人工验收，不应以自动化通过数量替代全部15项通过。
