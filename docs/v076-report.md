# 星栞 v0.7.6 交接与实际验证报告

日期：2026-11-03。versionName 0.7.6，versionCode 16。Android Jetpack Compose，手机本地执行，四页结构与绑定顺序不变；不增加自建服务器。

## 本版实现

- 账号默认标题优先使用已读取的官方角色昵称或官方名称与标签，保留独立用户备注及社区 UID 的脱敏补充行。角色 ID 不当作社区账号 ID，不从 UID 尾号拼造标签，不按昵称合并账号。仅有一条角色已在标题展示时，不再误报“角色待同步”。账号表、授权、绑定及签到记录结构未改动。
- 页面背景提供无背景、内置原创星海与系统照片选择器导入。选择器只授予单图读取；导入先暂存验证、受限解码及纠正方向、去除原始 EXIF，最后替换应用私有副本。坏图、超限和替换失败保留旧背景；图片大小上限20MB，导入长边2048，位图使用有界规划。
- 背景遮罩与模糊支持拖动预览、松手保存；文字与卡片不随背景一起模糊，低性能策略限制背景模糊。自定义图再次更换时使用内容修订号触发刷新，不依赖相同文件路径或相同偏好值碰巧变化。后台不回收仍被界面持有的位图。
- Dock 继续采样真实页面，升级 AGSL 边缘折射、色散、按压膨胀与方向性高光，保留拖动跟手、松手切页和冷启动捕获修复。图标和文字独立清晰绘制。修正了按压事件引用不匹配、未接入的高光输入及高光遮罩问题。
- 原创星轨书签启动图标、Android13单色图标、统一描边导航图标及星海书签形象已集成；人物只在设置品牌介绍中展示。素材来源和完整生成提示见 `brand-v076.md`。
- 设置增加手动检查更新，GitHub正式发布与夸克双通道。排除草稿、预发布、debug与无有效校验值的更新资源；按版本比较，拒绝降级。使用真实 GitHub `digest` 字段；网络、超时、限流和资源不完整分别反馈。
- 夸克永久入口 `https://pan.quark.cn/s/739482783865` 无需提取码；GitHub失败时仍能手动打开。更新由浏览器下载、用户确认系统安装。修正 Android 包可见性导致误报无浏览器：直接发起系统 Intent 并捕获无法打开异常，不用不可见的 resolveActivity 结果阻拦。
- 后续构建和 CI 改用 Release；新增 Windows 正式签名脚本及 `RELEASE_PROCESS.md`，每次正式发布按版本同步 APK、源码、报告与校验至 GitHub 和夸克。CI只提供未签名验证产物，不作用户安装包。

## 实际验证

最终 `assembleRelease`、`testReleaseUnitTest`、`lintRelease` 通过；317项单元测试，0失败、0错误、0跳过。Lint 0错误、22警告、2提示。JDK17、Gradle8.14.3、AGP8.8.2、Kotlin2.0.21、SDK35；依赖新增 ExifInterface1.3.7，无视觉库的大规模工具链升级。

在现有 MuMu game-1（Android15/API35，1920×1080）保留数据覆盖安装正式包，确认包名 `com.glasssign.app`、版本0.7.6、构建16，无DEBUGGABLE；正式证书与v0.7.5一致，v2/v3签名、zip alignment通过。旧 `.debug` 应用仍保留，未卸载或清理其账号数据库。

实际点击检查更新成功读取当时的 GitHub v0.7.5，不对较新的本机v0.7.6提示降级；切换夸克后按钮可用，系统 Activity 状态确认正确永久分享地址交给 Chrome。正式发布后可继续用相同入口查询。

实际通过系统照片选择器导入原创人物图，再更换星海图，页面即时变更；退出重启仍显示。删除用于验收的原始外部图片后重启，应用私有副本仍可显示。清除背景回到默认渐变。内置星海也经过退出重启验证。录屏包含底栏往返拖动及记录页切换；设置品牌形象实际渲染。截图、录屏、构建与冷启动像素检查明细随本地交付保存。

最终正式APK另做3次独立冷启动、无触摸导航图标像素检查，3次均检出389个主题蓝图标像素，Dock未重现空白。此检查仅对应当前MuMu分辨率与默认主题，不推广为全设备保证。
