# v0.7.5 交接与验证报告

日期：2026-11-02。版本0.7.5，versionCode15。Android Compose、本地执行、固定首页/账号/记录/设置四页；原包标识、密钥与schema5兼容。

## 用户反馈与实际原因

第二个森空岛账号在0.7.4修复签名后，用户已确认绑定成功；只读数据库核对为5个已绑账号、6项启用角色。用户手动签到后反馈“官方App成功，星栞首页报错”。

实测记录显示：原神、崩铁、绝区零、异环已为already/official；新账号明日方舟为success/accepted，森空岛社区为success/accepted；旧森空岛账号仍有授权检查失败，塔吉多社区任务failed。笼统总错误将这些不同任务混在一起，不能据此断言刚签的游戏失败，也不能把所有项改成成功。

后续只读测试还观察到短期签名令牌过期：旧、新森空岛会话都返回授权拒绝，官方GET续期却能成功恢复查询。旧账号的设备标识还保留了历史JSON对象格式。0.7.3只修新登录采集，不能自动修正已保存的旧数据。

## 已实现

- dsh分别实现Dock交互和前端反馈，主代理审查、修正集成并负责构建与MuMu验证。普通点击使用与可选Tab相同的父子触摸路径，避免透明手势兄弟层吞掉真实点击。
- Dock胶囊横向连续跟手、松手只切一次页、跨槽与边界夹紧、取消复位；保留真实页面采样、高斯模糊、独立AGSL、520dp居中限宽、无障碍Tab及减少动效。未复制FlClash源码或着色器。
- 冷启动截图检查发现过“可点击但未绘制”，语义测试不足以发现。最终在首次采样后显式刷新捕获节点，并在材质激活时重建一次临时渲染层；绘制顺序及独立合成明确。只在初始化切换一次，不引入空闲循环动画。
- 首页分别统计启用游戏/角色、社区奖励、授权检查，展示图标、状态、原因和处理入口。官方已签、接受提交、未知结果、未执行不混同；社区失败不改变已完成的游戏。
- 运行结果摘要保留在首页；旧worker错误在后续正常结束时清除。已接受但未核实的结果不会让标题宣称“全部完成”。来源不明的失败提供只读核对/记录入口，不承诺“安全重试这一项”。
- 森空岛每次角色发现前GET续期，解析并迁移历史设备缓存，保存新令牌与官方时间偏移后才继续。后续角色查询断网也不会丢失已经续期的本机授权。不生成随机设备指纹，不合并账号。
- 明日方舟只读GET签到日历已在MuMu确认：`data.currentTs`和`records[].ts`为秒级时间戳字符串，按官方日期及北京时间核对。查询签名包含实际编码的query串。
- 明日方舟签前查询，今日已有记录直接返回已签到；只有完整日历未含今日记录时才允许首次提交。提交后再次只读核对；未知结果保留保护，不重发。只读核对没有新结论时保留已有官方完成/接受提交记录。
- 正常授权验证成功后清理只读角色检查的旧失败占位，避免当天被旧发现锁继续拦住；真实签到历史、尝试次数和未知提交保护不清理。

## 验证

最终候选完整构建成功：assembleDebug、testDebugUnitTest、assembleDebugAndroidTest、lintDebug通过，JDK17、AGP8.8.2、Gradle8.14.3、SDK35。JVM189项通过，0失败、0跳过；lint无错误，22警告、2提示。

MuMu Android15最终48项设备测试通过：22项拖动、10项原Dock、实际shader渲染、导航、6项绑定布局、5项滚动布局、2项Android签名及1项真实授权/状态核对。最终运行18.179秒。普通触摸点击、跟手中间位置、松手一次回调、取消、边界、禁用、大字号及减少动效实际执行，未将语义点击等同普通触摸。

使用当前MuMu1920×1080实际截图像素验证：回归前3次、回归后3次独立冷启动均未触摸屏幕，导航图标可见。此证据只对应该模拟器与配置，不推广为全部Android设备结果。玻璃模式在对照实验后已恢复standard。

正常engine.verify/reconcile路径完成两份森空岛授权续期与旧缓存迁移，两个账号authState均为valid；新明日方舟今日记录由官方日历复核为already/official。当前5个账号、6项启用角色保留，5项有官方完成记录，余1项终末地尚未在本轮确认。此前塔吉多社区失败与森空岛社区仅接受提交记录仍分别保留，不伪装成功。

网络诊断只GET续期、角色和日历，不重做用户签到。真实凭据始终留在应用进程，日志只含脱敏状态与计数。带账号角色的截图、UI层级、APK、签名私钥不提交公开仓库。

## 继续开发与限制

终末地独立只读签到状态、塔吉多社区任务的实际响应含义仍未验证，不能宣称已经修好全部任务。社区失败仍需在记录里单独核对；本次不通过重新POST来猜测错误码。真实日历验证仅覆盖该明日方舟账号，首次提交/提交后确认的异常分支由合成测试覆盖。

未逐设备重测API26–32、真实手机长后台、完整读屏和不同厂商性能；MuMu不是所有真机的保证。FlClash风格的最终观感仍以用户体验为准，不宣称像素一致。v0.7.0的15项矩阵及前版领签独立应用扩展的限制继续有效。

正常构建：仓库根执行`android/gradlew.bat -p android -g .gradle-home --no-daemon --max-workers=2 :app:assembleDebug :app:testDebugUnitTest :app:assembleDebugAndroidTest :app:lintDebug`，JDK17。使用项目隔离缓存；不删用户共享Gradle缓存，不修改全局代理。

设备只选非破坏性测试类，不在已有账号的MuMu运行清库夹具。`SklandStoredAccountsProbeTest`默认跳过，`skland_stored_probe=true`仅诊断；额外显式`skland_repair=true`调用正常engine.verify/reconcile，保存续期授权及官方只读状态，但不提交签到。
